## Verificação reproduzível

Com R instalado, execute:

```bash
Rscript Docs/verificacao_estudo_caso_01.R
```

A verificação testa a viabilidade dos vértices, o lucro máximo de R$ 200,00, o segmento de soluções ótimas e o custo mínimo de R$ 240,00 na extensão com produção mínima de 80 unidades.
